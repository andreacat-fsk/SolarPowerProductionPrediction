# Solar Power Production Prediction
This repository contains solar power forecasting scripts and model analysis for both hourly and daily predictions. The raw data files are kept locally and can be provided on request.

## Repository structure
- `scripts/` — data collection and preprocessing scripts
- `Hourly model on gsps/` — hourly prediction models, notebooks, and forecasts
- `Daily model on pes regions/` — daily model reports and analysis
- `requirements.txt` — Python dependencies
- `LICENSE` — project license

## Setup
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Notes
- `venv/` and local environment files are not included in the repository.
- Large dataset files are stored locally only and not committed here.
- If you need the raw data, please request it and I can share it separately.
